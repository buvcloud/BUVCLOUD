BUVCloud Next.js website project

Folder structure:
  app/page.jsx                 Homepage structure and sections
  app/page.css                 Website styling and responsive layout
  app/layout.jsx               Root layout and metadata
  public/images/buvcloud-globe.png  Globe visual asset
  package.json                 Dependencies and npm scripts
  next.config.mjs              Next.js configuration
  eslint.config.mjs            ESLint configuration

Run in VS Code:
1. Extract this ZIP to a normal folder.
2. Open the extracted BUVCloud_Project folder in VS Code (File > Open Folder).
3. Open Terminal > New Terminal.
4. Run: npm install
5. Run: npm run dev
6. Open http://localhost:3000

Production check:
  npm run build

Note: The project files are bundled in this ZIP with their folder structure intact.
The site has not been verified in the user's local browser. Login and signup routes
are links only; those pages/backend are not included in this homepage starter.
